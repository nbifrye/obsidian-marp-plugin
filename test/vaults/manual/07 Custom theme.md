# カスタムテーマ

`themes/sample.css`（`/* @theme sample */`）

---

## 確認すること

- 背景が斜線のストライプ（テーマから相対 `url()` で参照した `themes/stripe.svg`）
- 見出しがオレンジ色で下線付き
- `@import 'default'` で既定テーマのスタイルを継承している
- `themes/sample.css` を編集して保存するとプレビューに反映される
- 設定の **Theme folder** を空にすると既定テーマに戻る
